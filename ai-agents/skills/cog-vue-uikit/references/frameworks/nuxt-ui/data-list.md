# 목록 화면 (@nuxt/ui)

`../../common.md` 의 목록 원칙을 @nuxt/ui(UTable, USelectMenu 등)로 구현할 때의 규칙. px 실측값은 예시 프로젝트에서 잰 것이며 루트 글자 크기가 16px 일 때의 값임(옛 문서의 일부는 18px 에서 쟀고 그 값은 8분의 9로 작아짐). 그 값을 그대로 옮기지 않고 다시 잼.

## 컬럼 너비는 table-auto 가 기본
표는 auto 로 두고 폭은 고정하고 싶은 컬럼에만 줌.

- fixed 를 기본으로 두지 않는 이유 하나: 컬럼 하나만 고정할 수 없음. 안 준 컬럼이 전부 균등으로 묶이므로 체크박스 하나만 좁히려던 표가 나머지 컬럼까지 폭을 강제당함.
- 이유 둘: 지정 폭을 넘는 값이 오면 글자가 옆 칸을 덮음. 폭이 어긋나는 것보다 글자를 못 읽는 것이 나쁨.
- auto 의 대가는 폭이 데이터를 따라 움직인다는 것임. 그것이 못 견딜 표만 fixed 로 올리고 이때는 모든 컬럼에 폭을 줌.

| | table-fixed | table-auto |
|---|---|---|
| 폭을 정하는 근거 | 첫 행의 지정 폭만 봄 | 모든 행의 내용을 봄 |
| 지정한 폭 | 상한이자 하한 | 하한(모자라면 그 열만 벌어짐) |
| 폭을 안 준 컬럼 | 남은 폭을 균등 분배 | 내용대로 나눠 가짐 |
| 지정 폭보다 긴 값 | 못 끊는 글자는 칸 밖으로 넘쳐 옆 칸과 겹침 | 못 끊는 글자는 그 열이 넓어짐 |

### 케이스별 폭
1. 전부 내용대로: 아무 폭도 주지 않음.
2. 한 컬럼만 고정하고 나머지는 가변(기본): 컬럼의 `meta: { class: { th: 'w-24' } }` 로 헤더에 w-* 를 주고 나머지는 손대지 않음. 셀은 nowrap 임(표 컴포넌트가 td 를 truncate 로 주므로 이미 nowrap, UTable 을 직접 쓰면 셀에 whitespace-nowrap 을 줌).
   - 나머지 칸이 모두 nowrap 이면 w-* 도 눌릴 수 있음. 이때는 `w-* min-w-*` 를 함께 줌. min-w-* 만 주면 넓을 때 남는 폭을 받아 늘어남.
   - nowrap 은 두 줄 금지(값이 갈리는 것을 막음)이지 폭을 고정하려는 것이 아님. 지정 폭을 넘는 값이 오면 그 열이 벌어짐.
3. 폭이 데이터를 따라 움직이면 안 되는 표: fixed 와 모든 컬럼에 폭.
- auto 에서 퍼센트를 섞지 않음. 퍼센트가 폭을 모두 가져가면 픽셀로 준 컬럼이 눌려 선언값이 지켜지지 않음. 퍼센트는 fixed 의 문법임.
- 기본 폭은 정렬 아이콘을 빼고 잡음. auto 에서는 정렬한 순간 그 열이 스스로 벌어지므로 미리 비워 두면 평소에 빈 칸만 남음.
- 가운데 정렬은 `meta.align: 'center'` 하나만 적음. 표 컴포넌트가 셀에 text-center 를 붙이고 헤더 버튼을 justify-center 로 돌림. 헤더에 클래스를 줘서는 안 움직임(헤더 버튼이 w-full 로 칸을 채우고 자기 justify 를 가짐).
- meta 를 상수로 뺄지는 횟수가 아니라 같아야 하나 우연히 같나로 가름. 한 칸이나 우연히 같은 값은 칸 정의에 직접 적고, 한 파일의 여러 칸이 같아야 하면 그 컬럼 파일의 상수(내보내지 않음)로 두며 왜 같아야 하는지 한 줄을 적음. 막는 실수: 같아야 하는 것을 칸마다 적다가 하나를 빠뜨려 머리글이 꺾이는 일.
- 줄바꿈을 막을 때는 th 에도 거는 `{ th: 'whitespace-nowrap', td: 'whitespace-nowrap' }` 로 줌. 값이 머리글보다 짧은 칸은 폭이 값에 맞춰 좁아져 머리글이 꺾임.

### fixed 로 올릴 때
- fixed 에서 잰 값이므로 auto 에서는 다시 잼.
- 함정 셋: 폭을 안 준 컬럼은 알아서 되지 않고 균등 분배를 받음. px 만 주면 고정되지 않고 비율로 쓰여 다 같이 커짐. max-width 는 브라우저가 표 셀에서 무시함.
- 고정 컬럼(값 종류가 정해진 상태, 날짜, 분류)은 px 로, 가변 컬럼(길이가 안 정해진 이름, 계정)은 분수(w-1/5, 합 100%)로 줌. 둘 다 meta.class.th 로 주고 meta.style.th.width 를 섞지 않음(폭을 말하는 방법이 둘이 됨). 소수점을 쓰지 않음. 가변 컬럼까지 px 로 통일하면 좁은 화면에서 가로 스크롤이 생김.
- 고정 컬럼은 대개 셀이 아니라 헤더 글자가 폭을 정함. 헤더는 글자 더하기 버튼 패딩과 정렬 아이콘, 셀은 글자 더하기 셀 패딩이고 둘 중 큰 값을 씀. 아이콘은 정렬됐을 때만 나오므로 정렬된 상태 기준으로 잡음.

## 표에 함께 주는 것
표 컴포넌트가 이미 주는 것이고, UTable 을 직접 쓰면 쓰임에 맞춰 고름.
- `w-full`: 테마의 min-w-full 이 우리 min-w-* 에 밀림. 없으면 넓은 화면에서 표가 최소폭에 멈춰 오른쪽이 빔.
- min-w-* 는 기본으로 주지 않음. 하는 일은 고정을 지키는 것이 아니라 좁을 때 잘림 대신 가로 스크롤을 택하는 것임.
- `td: 'truncate'`: 테마 td 에 whitespace-nowrap 이 있어 안 자르면 옆 칸을 침범함.
- `thead: 'bg-default backdrop-blur-none'`: sticky 를 쓰면 반드시 같이 줌. sticky 변형이 반투명 배경과 blur 를 걸어 스크롤되는 행 글자가 헤더를 뚫고 비침. 확인할 때 행이 헤더 한가운데를 지나도록 스크롤을 조정해야 보임.
- 스크롤되는 표의 테두리, 라운드, overflow-hidden 은 바깥 래퍼가 갖고 스크롤은 안의 표가 함(`<div class="border-default flex min-h-0 flex-1 overflow-hidden rounded-md border"><UTable class="flex-1" sticky /></div>`). 스크롤 컨테이너 자신에게 주면 스크롤바가 둥근 모서리 위에 얹힘.

## 정렬 헤더
enableSorting: true 만으로는 헤더가 클릭되지 않음. 토글을 부르는 버튼을 직접 그림(표 컴포넌트의 헤더 부품이 이 모양).
- 버튼이 th 를 꽉 채움: 표에 `ui.th = 'p-0'`, 버튼에 `w-full px-4 py-3.5`. 음수 마진 방식은 임의값이 필요함.
- 정렬 가능 여부를 정적으로 표시하지 않음(미정렬 아이콘, 굵기와 색 차이). 호버로 구분함(ghost 배경이 셀 전체에 깔리고 정렬 안 되는 컬럼만 안 뜸).
- cursor-pointer 를 반드시 넣음. Tailwind v4 preflight 가 button 의 기본 포인터를 없앴음.
- rounded-none 을 줌. 버튼이 셀을 채우므로 기본 모서리가 남으면 호버 하이라이트만 둥글음.
- toggleSorting() 을 인자 없이 부름. 오름, 내림, 해제 3단계가 됨. 인자를 주면 백엔드 기본 정렬로 돌아갈 방법이 없어짐.
- font-semibold text-highlighted 를 되돌려 줌. UButton 의 font-medium 이 th 테마를 덮어써 정렬 버튼이 있는 헤더만 얇고 흐려 보임.
- 백엔드가 정렬을 지원하지 않는 컬럼에는 버튼을 그리지 않음.

## 행을 눌러 열기
- UTable 은 onSelect 라는 함수 prop 으로 행 클릭을 받음(defineEmits 가 아님). 체크박스 선택(v-model:row-selection)과는 별개임. 데이터는 row 가 아니라 row.original 임.
- button 과 a 안의 클릭은 UTable 이 걸러서 체크박스를 눌러도 행 클릭이 안 돔.
- cursor-pointer 는 직접 줌(테마는 hover 배경과 focus outline 만 줌).
- 표 컴포넌트가 $attrs 를 통과시키지 않으면 새 prop 은 명시적으로 뚫어야 함. 부모가 `@select` 를 쓰면 리스너가 루트 div 에 붙어 조용히 아무 일도 안 하고 타입 에러도 안 남.
- 켜는 것은 함수 prop 이 있을 때만 함. 플래그를 따로 두면 둘이 어긋나고 항상 켜면 안 쓰는 표의 행에도 role=button 과 tabindex 와 hover 가 붙음.
- 키보드로는 못 열 수 있음(role 과 tabindex 는 붙지만 keydown 핸들러가 없고 tr 을 직접 그리지 않아 밖에서 붙일 자리가 없음).

## 컬럼 정의
- 컬럼은 `DataTableColumn<Row>[]` 같은 타입으로 선언해 헤더가 문자열이 아니면 타입에서 막히게 함.
- 헤더 컴포넌트는 .vue 여야 함(.ts 에서는 resolveComponent 가 인스턴스 컨텍스트를 못 잡음). h() 를 통과하는 prop 은 제네릭이 아니라 구조적 타입으로 둠(제네릭은 unknown 으로 떨어짐).
- UTable 의 defaultColumn prop 은 쓸 수 없음. processColumns 가 cell 없는 컬럼에 자기 렌더러를 먼저 넣어(빈 값이면 `&nbsp;`) 빈 값을 가질 수 있는 컬럼마다 cell 을 직접 달아야 함.
- 셀을 직접 그리려면 `#<컬럼id>-cell` 슬롯이며 컬럼 id 를 바꾸면 슬롯 이름도 같이 바꿔야 하는데 타입이 안 잡아 줌.

## 뱃지와 막대
- 막대는 한 줄에 여러 정보가 담긴 목록과 카드에서 그 줄의 상태를 한눈에 보이려고 줄 앞에 둠. 표처럼 칸 하나가 상태 하나만 말하면 뱃지임.

| 자리 | 표식 | 모양 |
|---|---|---|
| 표의 상태 칸 | 뱃지 | subtle, size md, `w-12 justify-center`. 칸은 `w-24` 와 가운데(meta.align) |
| 이름 줄 옆의 분류 | 뱃지 | subtle, 기본 크기, shrink-0, 분류는 줄 오른쪽 끝(ml-auto) |
| 한 셀 안의 칸 라벨 | 뱃지 | soft, `w-28` |
| 건수 | 글자 | `text-muted text-sm`, 뱃지로 감싸지 않음 |

- variant 는 subtle(값)과 soft(칸 라벨) 둘만 쓰고 outline 과 solid 는 쓰지 않음. 같은 분류가 목록마다 다른 모양으로 갈리지 않게 함. 색은 cog-vue 의 색의 뜻을 따름.
- 대비는 Nuxt UI 기본값을 따름. 밝은 화면의 색 subtle 뱃지 글자는 AA 에 못 미치지만 variant 로는 안 풀리고 테마를 덮어쓰지 않음(예시 프로젝트에서 잰 값).
- 뱃지는 행 높이를 정함. 셀 패딩과 일반 글자 줄 높이보다 뱃지가 자기 패딩 때문에 커서 상태 컬럼 하나가 행 전체를 밀어 올림. 모든 표의 상태 뱃지는 md 로 통일함. 칸 글자와 높이를 맞출 일이 있으면 줄 높이 숫자가 아니라 기준선 맞춤(align-baseline)으로 함.
- 행 안의 동작 버튼은 채운 모양(variant 를 적지 않음)에 size sm 을 씀. 줄마다 붙어도 그 화면의 주 동작이라 채움. 색은 동작이 정함(생성 success, 수정 warning, 삭제 error).

## 좁은 목록 패널의 필터
- 필터 버튼과 팝오버 안에 원래 크기 셀렉트를 넣고, 고른 값은 검색창 아래 칩으로 보임(고른 필터가 없으면 줄이 없음). 칩 라벨과 풀기는 useListQuery 의 selectedFilters, clearFilter(key), resetFilters() 가 줌. 화면은 전체의 내부 값(UNSELECTED)을 몰라도 됨.
- 필터 옵션을 필터 밖에서도 쓰면 useListQuery 의 filterOptions 를 받음. 페이지가 옵션 요청을 따로 들지 않음.
- 짝 필터를 푸는 watch 는 flush: 'sync' 로 줌. 늦으면 뒤의 것만 남은 요청이 한 번 더 나감.
- 전체의 값은 '' 가 아니라 'unselected' 임. reka-ui 가 '' 를 SelectItem 의 값으로 받지 않기 때문이고, 이 값은 쿼리에 실리지 않음.

## 선택지와 빈 문구
- 빈 목록 문구는 Nuxt UI 한국어 기본 문구(noData)와 같음. 검색되는 셀렉트(USelectMenu)는 기본(noMatch)대로 일치하는 데이터가 없다는 문구가 나오고 덮어쓰지 않음.
- USelectMenu multiple 에는 clear 를 줌(고른 것이 있을 때 칸 오른쪽의 버튼 하나로 모두 비움). 버튼은 기본 모양 그대로 둠.
- 서버 검색을 쓰는 USelectMenu 는 기본 필터를 끔(common 의 선택지 원칙).
- 표를 무한 스크롤로 그리면 has-more 와 load-more 를 넘김. 바닥 감지(useInfiniteScroll)와 다시 시도 줄은 표 컴포넌트가 갖고 서버에서 다음 쪽을 받는 일은 useInfiniteFetch 가 함. has-more 를 넘기지 않은 표는 둘 다 하지 않음. 줄 높이가 같은 목록은 목록 부품에 row-height, has-more, load-more 를 넘기고 줄은 `#row` 슬롯으로 줌.
