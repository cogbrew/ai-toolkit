# 페이지 헤더와 액션 배치 (@nuxt/ui)

`../../common.md` 의 페이지 헤더 원칙을 구현하는 규칙. 크기 값은 예시 프로젝트에서 루트 글자 크기 16px 로 정한 것임. 일부 실측값은 18px 에서 잰 것이라 8분의 9로 작아지므로 다시 잼.

## 제목과 부제
| 요소 | 값 |
|---|---|
| 제목 | `<h1 class="text-highlighted text-2xl font-semibold">`, 라우트당 1개 |
| 부제 | `<p class="text-muted mt-1 text-sm">` |

- 부제가 text-base 가 아닌 이유: text-base 는 문단으로 읽히는 산문이고, 목록 화면은 표와 필터와 건수가 모두 14px 라 부제만 16px 이면 안내문이 두 번째로 큰 글자가 됨.
- 본문 산문에는 text-base 를 그대로 씀(에러 페이지처럼 본문이 그것뿐인 경우). 이때는 크기 클래스를 붙이지 않음(기본이 16px).
- 제목과 부제는 라우트 메타로 메뉴를 찾아 그 name 과 description 을 씀. 화면은 `<AppPageHeader>` 만 두고 아무것도 넘기지 않음.

## 액션 정렬
- 액션 버튼은 제목 락업의 세로 가운데임(items-center). items-start 면 버튼이 제목 윗변에 붙어 부제가 있는 화면에서 어긋남. 중심이 맞는지는 눈이 아니라 getBoundingClientRect() 로 봄.

## 크기감은 폰트가 아니라 아이콘과 패딩
- 넉넉해 보여야 하는 오버레이는 큰 아이콘, 큰 아이콘 박스, 넉넉한 패딩으로 만듦. size 프리셋이 아이콘까지 줄이므로 아이콘은 따로 고정함.
```vue
<UButton size="lg" :ui="{ leadingIcon: 'size-7' }" :icon="…" />
```
- 답답해 보이면 폰트를 되돌리지 말고 패딩, 아이콘, 행간으로 품.

## 아이콘 배율
- 아이콘은 라벨 크기의 1.2배에서 1.5배 안에 둠(16px 라벨에 24px 아이콘은 1.5배). 14px 라벨에 24px 아이콘이면 1.71배라 과함.
- 아이콘만 줄이면 박스 안쪽 여백이 벌어져 박스가 헐거워지므로 박스도 함께 내림.
- 라벨이 숨는 자리(좁은 화면에서 아이콘만 남는 분류 레일)는 예외로 크게 유지함. 취향이 아니라 동작에 근거한 차이임.

## 건수
- 건수 글자는 text-muted text-sm 이며 뱃지로 감싸지 않음. 페이지네이션 줄의 건수와 패널 제목 줄의 건수가 같은 글자임.
