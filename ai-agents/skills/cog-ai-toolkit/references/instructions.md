# 지침 문서 작성 기준

`ai-agents/AGENTS.md` 와 도구별 지침 파일에 적용한다. 근거가 「공식 문서」인 항목은 해당 도구 문서에서 확인한 것이다.

| 기준 | 근거 |
|---|---|
| 한 파일은 Claude 200줄 이하, Antigravity 24 KB 이하, Codex 합계 32 KiB 이하 | 공식 문서 |
| 주제별 제목과 불릿으로 구성하고 긴 문단은 쓰지 않는다 | Claude 공식 문서 |
| 항목은 구체적이고 검증 가능하게 쓴다. 예: 「Format code properly」 대신 「Use 2-space indentation」 | Claude 공식 문서 |
| 서로 부딪치거나 모호한 지시를 두지 않는다. 새 규칙을 넣을 때 기존 규칙과 충돌하는지 먼저 확인한다 | Claude 공식 문서(충돌 시 임의로 하나를 고름) |
| 여러 단계 절차와 특정 작업에만 필요한 내용은 지침이 아니라 별도 문서나 스킬에 둔다 | Claude 공식 문서 |
| 반드시 지켜야 하는 것은 지침 문구에 더해 hook·권한 설정으로 강제한다. 지침은 강제가 아니라 맥락이다 | Claude 공식 문서 |
| 지켜야 할 행동과 예외를 함께 적는다 | Codex 공식 문서(코드 리뷰 맥락) |
| 같은 개념에는 같은 말만 쓰고, 비유는 풀어 쓴다 | 판단(시험에서 실패는 없었음) |
| 반영하기 전에 사본을 시험한다 | 이번에 한 방식 |

- 명사형 종결 통일은 개인 규칙 문서(`ai-agents/AGENTS.md`)에 적용한다. 저장소 작업 문서(루트 `AGENTS.md`, 이 스킬의 문서)는 서술형으로 쓴다.
- 다른 파일을 불러오는 문법은 도구마다 다르다. Claude 는 `@경로`(불러오는 파일 기준 상대 경로), Antigravity 는 `@[라벨](경로)`, Codex 는 문법이 없다.
